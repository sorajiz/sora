# Sora — Personal Profile & Portfolio ✨

A modern, fluid glassmorphism profile website for **Mezy310 (Sora)**, featuring dynamic animated silk wave aesthetics, smooth-scroll navigation, and interactive portfolio showcases.

## 🚀 Features

- **Dynamic Animated Silk Background**: Multi-layered silk waves with subtle breathing keyframes, soft-light shimmer flows, and mouse-parallax responsiveness.
- **Sticky Glassmorphic Navigation**: Featuring 4 core sections:
  - **Home**: Hero introduction, status badge, and highlight metrics.
  - **Intro**: Detailed developer story, values, and project focus.
  - **Skills**: Technical arsenal with visual proficiency bars (Frontend, Backend & Bots, Tools & Ecosystem).
  - **Contact**: Glass inquiry form, direct links, and one-click copy email with floating toast feedback.
- **Optimized for Vercel**: Zero-config static architecture with fast loading and high responsiveness across all devices.

## 🛠️ Tech Stack

- **Core**: HTML5 Semantic Architecture, Vanilla JavaScript (ES6+)
- **Styling**: Modern CSS3 (Glassmorphism, CSS Custom Properties, Animations)
- **Typography**: Plus Jakarta Sans & Outfit (Google Fonts)
- **Icons**: Lucide Icons
- **Deployment**: Vercel ready (`vercel.json`)
